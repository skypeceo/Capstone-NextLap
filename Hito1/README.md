## How to run

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
# Copy the released base_NextLap/ folder to the repository root (it is git-ignored), or pass its path:
python run_reference.py --base /path/to/base_NextLap
```

The script asserts row counts (5,772 / 1,808), rounds (1–7 / 8–9), unique and disjoint
`pair_id`s and that no `next_*` column is an input, then writes `outputs/`. No test data is used.
