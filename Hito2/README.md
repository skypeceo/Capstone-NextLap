## Data

Released `IIT414W_Capstone_NextLap_StudentData_v1` (folder `base_NextLap/` of the course package). Not duplicated here: copy `base_NextLap/` to the repository root (it is git-ignored). Uses the nine raw race snapshots in `base_NextLap/data/` (SHA-256 verified against `source_manifest_v2.json` by `load_snapshots`) and the clean train/validation tables. SHA-256 of the inputs actually read are saved in `outputs/hito2_run.json`. No reserved test data used; no prior access.

## Environment and commands

From the repository root:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r Hito2/requirements.txt            # Python 3.13.5; versions pinned in requirements.txt
python Hito2/build_features.py                   # 1) feature + availability checks
python Hito2/run_hito2.py --explain k3           # 2) comparison, ablation, errors, SHAP
```

`run_hito2.py` also asserts that the validation `pair_id`s equal the frozen Hito 1 list (`Hito1/outputs/validation_pair_ids.txt`).
